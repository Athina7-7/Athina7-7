### La transformación comienza con la práctica.

**De emprendedor a emprendedor.**

Estoy creando **Askesis**, una iniciativa tecnológica que busca acercar soluciones de ingeniería a emprendedores y pequeños negocios de una manera accesible, práctica y humana.

Creemos que la tecnología debe partir de las personas: escuchar sus necesidades, comprender sus dificultades y construir soluciones que realmente tengan sentido para sus negocios.

<img src="https://img.shields.io/badge/Voice_Interaction-52796F?style=flat-square" alt="Interacción por voz"/>

**Prepárate para tu próxima entrevista con inteligencia artificial.**

Aplicación web conectada a inteligencia artificial que simula entrevistas por voz en tres modalidades: general, por carrera y por cargo. Personaliza las preguntas, evalúa las respuestas y ofrece sugerencias para mejorar, además de guardar un historial de las sesiones.

Su experiencia está centrada en la comunicación oral, sin respuestas escritas mediante teclado, para ofrecer una práctica más cercana a una entrevista real.
